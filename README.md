# Mohar

Show the rule. Explain the mismatch. Support the fix. Leave the decision with a person.

Mohar is a pre-publication review desk for brand teams. Paste a draft, or drop a PDF, Word or text file.
Mohar checks it against the organisation's approved guidelines, facts, terminology and visual identity.

- Every finding names the rule or approved fact behind it, with a verdict (Confirmed / Likely / Needs review) and a suggested edit.
- Creators accept, edit or dismiss each suggestion, and every dismissal needs a reason.
- A reviewer approves or requests changes. Version history and an audit trail record every step.
- A compliance score and a Guideline Health view show which rules people keep breaking.

**Content types:** advertisement, social post, email, newsletter, SMS, website copy, blog article, document or PDF.

## Run it
Open `index.html` with VS Code Live Server. No build step and no backend. It needs internet for fonts and the PDF and Word readers.

## Limits
No AI model is used in this build. Every finding comes from the rule engine. Scanned PDFs need OCR, which is not included. Data is stored in the browser only.
